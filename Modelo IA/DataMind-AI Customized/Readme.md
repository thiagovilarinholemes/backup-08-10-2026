## ⚙️ Criando o Ambiente Virtual Python

Para criar o Ambiente Virtual Python digite os comandos abaixo

```
# Cria o Ambiente Virtual
python -m venv .venv

# Ativa o Ambiente Virtual
.venv\Scripts\activate

# Desativandoo o Ambiente Virtual
deactivate
```
